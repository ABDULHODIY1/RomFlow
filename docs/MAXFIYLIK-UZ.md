# Maxfiylik siyosati — RomFlow

RomFlow hisob ochishni talab qilmaydi va foydalanuvchi ma’lumotlarini
serverga yubormaydi.

## Qurilmada nima saqlanadi
Ustaxona nomi va telefoni, mijozlar (ism, telefon, manzil), smetalar,
buyurtmalar, to‘lovlar, qarzlar, razmerlar, ombor, xodimlar, narxlar va
sozlamalar — ilovaning qurilmadagi ajratilgan papkasida. Claude AI kaliti
alohida faylda, zaxira nusxaga yozilmaydi.

## Internet qachon ishlatiladi
| Nima uchun | Qayerga | Nima yuboriladi |
|---|---|---|
| Dollar kursi | cbu.uz, zaxira: open.er-api.com | Hech narsa (faqat so‘rov) |
| Zavodlar narx katalogi | raw.githubusercontent.com | Hech narsa (faqat so‘rov) |
| Narx havolalari | Siz qo‘shgan manzil | Hech narsa (faqat so‘rov) |
| AI kamera (ixtiyoriy) | api.anthropic.com | Siz tanlagan rasm, faqat o‘z kalitingiz bo‘lsa |

Kamera faqat rasm yoki jonli ko‘rinish uchun; ovoz yozilmaydi. Eslatmalar
qurilmaning o‘zida rejalashtiriladi.

## Ulashish
PDF, matn yoki JSON zaxira faylini qayerga yuborishni o‘zingiz tanlaysiz.
Ilovani o‘chirsangiz, ma’lumotlar ham o‘chadi — avval zaxira saqlang.
Sozlamalar → “Mahalliy ma’lumotlarni tozalash” hammasini o‘chiradi.

Savollar uchun repodagi Issues bo‘limidan foydalaning.
